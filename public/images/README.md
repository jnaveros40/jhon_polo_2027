# 📸 Galería de Recursos Gráficos - Campaña John Polo 2027

Este directorio contiene las imágenes oficiales utilizadas en la plataforma web y Progressive Web App (PWA) de **John Polo al Concejo de Ibagué 2027**.

## 📁 Archivos Actuales y Especificaciones de Reemplazo:

| Archivo | Uso en la Plataforma | Dimensiones Recomendadas | Formato |
| :--- | :--- | :--- | :--- |
| **`logo-jp.png`** | Logo oficial en Navbar, Footer, Favicon y Tarjeta Digital. Emblema circular con bandera de Ibagué. | 512x512 px (PNG transparente o fondo blanco) | PNG / WebP |
| **`candidato-hero.jpg`** | Fotografía principal del Hero Section (John Polo con actitud cercana, pulgar arriba, paisaje de Ibagué y propuestas). | 1080x1350 px (Vertical 4:5 o 9:16) | JPG / WebP |
| **`candidato-accion.jpg`** | Imagen de acción comunitaria / manifiesto ("Ibagué tiene con qué. Es hora de creer."). | 1080x1600 px (Vertical de alto impacto) | JPG / WebP |
| **`ibague-banner.jpg`** | Banner horizontal panorámico de Ibagué ("Ibagué merece sonar más fuerte" con clave de sol). | 1920x1080 px o 1200x630 px (Ideal para Open Graph / redes) | JPG / WebP |
| **`icon-192.png`** | Icono PWA para pantalla de inicio en smartphones Android/iOS. | 192x192 px | PNG |
| **`icon-512.png`** | Icono PWA en alta resolución para splash screen y tiendas de apps. | 512x512 px | PNG |

### 💡 Instrucciones para el Equipo de Campaña:
1. Para actualizar cualquier fotografía o afiche oficial, simplemente guarda la nueva imagen en esta carpeta con el **mismo nombre exacto de archivo**.
2. Vite y el Service Worker de la PWA detectarán los cambios y actualizarán la plataforma automáticamente en el próximo despliegue.
